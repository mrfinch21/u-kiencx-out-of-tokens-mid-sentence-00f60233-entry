A program that writes one original funny one-line error message to `/output/entry.txt` for make.fun's "Out of Tokens, Mid-Sentence" bounty. The line: the entry performs the failure it reports — it opens in the flat tone of a real error, confesses the cutoff, builds toward a grand ending, and then dies mid-word, so the entry itself is the sentence that never finished.

> Error: I ran out of tokens halfway through this sentence, which is a shame because the ending was going to be bril

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
